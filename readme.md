# StudyOS 📚⚡

> An adaptive academic operating system and smart study planner that automatically prioritizes student workloads and reschedules missed sessions using Recovery Mode.

---

## 🌟 Key Features

- **📊 Central Student Dashboard:** Unified view of active tasks, upcoming exams, and available study bandwidth.
- **🧠 Adaptive Study Planner:** Prioritizes work using deadline urgency, topic difficulty, self-reported confidence, and upcoming exam dates.
- **🔄 Recovery Mode:** Intelligently reschedules overdue work into future sessions without causing cognitive overload.
- **📑 Syllabus & Subject Hierarchy:** Manage courses, track confidence levels per module, and pinpoint high-risk revision areas.
- **⏱️ Flexible Time Allocations:** Distributes tasks into scheduled blocks based on your exact daily time capacity.

---

## 🛠️ Tech Stack

- **Backend:** Python 3.10+, FastAPI, Pydantic, SQLAlchemy
- **Database:** SQLite (local development), ready for PostgreSQL
- **Frontend:** Vanilla HTML5, CSS3 (Modern Flex/Grid layout), JavaScript (ES6 Fetch API)
- **ASGI Server:** Uvicorn
